# 验证范围

## 外观基线

用户当前使用的配置已在 Windows 11 build 26200 / Explorer 10.0.26100.9444 上调试，确认圆角、时钟显示完整、原生搜索、左下角空白不触发、应用区域与托盘区域可唤起。用户重启后确认启动速度可接受。

这验证了预设的实际使用效果，不等于新分发包已在所有 Windows 11 版本验证。

## 自动检查

tests/Validate.ps1 使用临时文件夹、随机独立注册表测试键及模拟的进程和任务：

- Windows PowerShell 5.1 语法与 UTF-8 BOM 编码。
- 依赖清单、官方地址、SHA256 格式与预设结构。
- 下载内容校验、损坏缓存拒绝、正确缓存复用和路径越界拒绝。
- Windhawk 配置生成、UTF-16 LE 编码与运行库目标名称。
- 注册表单值恢复、原先缺失值的恢复、保留后续外部修改。
- 应用前持久化撤回记录、重复应用不覆盖原备份。
- 恢复原启动状态和快捷方式；加载失败自动撤回。
- 重复恢复不再次修改。

测试不会启动 Windhawk、改变真实任务栏、创建真实登录任务或下载第三方文件。随机测试键结束时删除，临时测试文件保留，便于审查。

## 分发核查

依赖版本对应的官方模组源码与现有已使用的模组程序已核对 SHA256。发布 ZIP 采用允许清单，只包含本项目源文件、配置、说明、许可及用户提供的桌面效果截图，没有第三方二进制、缓存、个人路径、独立壁纸文件、聊天截图或恢复记录。

## 尚未覆盖

新电脑上的首次联网安装、不同 Windows 补丁、多屏、高 DPI、ARM64、组织策略、其他美化软件冲突以及突发断电没有完整实机回归。新包的一键管理流程通过隔离模拟验证；现有桌面保持原配置，没有用新包覆盖以伪称完整实机验收。

因此本版应先试用并保留恢复入口，首次公开发布建议标记为试用版本。DLL 加载检查只确认模块存在，不保证每个视觉行为都符合预期。

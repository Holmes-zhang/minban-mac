# Beta 测试说明

版本：1.1.0-beta.1。此版包含独立图标提醒，适合愿意反馈问题的Windows 11 x64用户。下载完整切换包、解压、运行“应用民办mac.cmd”；不要只下载一个cmd文件。

## 请重点观察

1. 启用后，鼠标在应用组和时间组下方能否唤起，空白区域是否不触发。
2. 鼠标离开后是否及时收回；QQ最大化后关闭、背景仍有最大化窗口时是否出现几秒延迟。
3. QQ或微信最小化且仍有任务栏按钮时，新消息是否让对应图标从原位置升起，约1.2秒后收回。
4. 调整应用排列后，提醒是否跟随当前按钮；两个应用同时提醒时是否各自显示。
5. “关闭独立提醒.cmd”能否只关闭提醒；重新应用后是否保留关闭选择。
6. 重启后能否自动加载；“恢复原任务栏.cmd”能否恢复启用前的启动项和显示设置。

## 已知问题与行为

- QQ曾在本机重启后恢复提醒；只发送系统通知、不发任务栏闪烁信号时可能没有独立提醒。
- 窗口切换后任务栏迟收回的问题仍待复测，不宣称已完全修复。
- 同一屏幕还有可见最大化窗口时会允许自动隐藏，即使前面是普通小窗口。桌面没有这类窗口时保持常显。
- 默认阻止其他程序争用XAML诊断接口，优先保留本套任务栏样式；TranslucentTB等相关功能可能因此无法生效。应用流程会记录并暂停原有TranslucentTB启动状态，完整恢复时按记录撤回。
- 多屏、所有缩放比例、不同Windows补丁和全新电脑首次安装尚未完整实机回归。
- 源码及安装恢复流程的隔离检查不等于这些场景全部通过。

## 反馈什么最有帮助

说明Windows版本、屏幕数量与缩放比例、应用名称、任务栏是否有该应用图标，以及问题出现前的几步操作。截图可遮住聊天内容和个人信息。请勿公开本机state.json、备份或含私人路径的恢复记录。

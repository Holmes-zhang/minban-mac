# 故障处理

## 旧版报“在此对象上找不到属性 Execute”

请下载 1.0.1 或更新的切换包，完整解压后重新运行“应用民办mac.cmd”。1.0.0 在扫描部分系统 COM 任务时会触发此错误，1.0.1 已跳过这些任务。

截图中的这类报错发生在暂停原方案之前。无需删除 %LOCALAPPDATA%\MinbanMac 的缓存或恢复记录，新版会复用已校验的官方下载文件。如果错误信息不同，请保留原提示以便排查。

## 下载失败或卡在首次准备

首次需下载约 142 MiB 的安装包及数个小文件。慢网络可能需要几分钟。确认能访问 GitHub 和 mods.windhawk.net，必要时使用“网络设置.cmd”填写本机代理。脚本不会将错误页当作安装包运行。

1.0.2 起，常规下载失败后自动尝试 Windows 自带下载器。两条路径都会校验 HTTPS 证书，不会降低成 HTTP 或跳过证书检查。新版正常退出时会清理本次的未完成临时文件；早期版本或窗口被强制关闭留下的 .download-… 文件没有被执行，退出所有切换窗口后可自行清理。

SHA256 不符时会停止。已有正式缓存不会自动删除或覆盖；按错误中的路径保留或移走该文件后重试。

## 报“未能为 SSL/TLS 安全通道建立信任关系”

这表示下载链路没有通过证书信任检查，不代表任务栏已经应用。只凭这一提示无法判断是系统时间、根证书更新、代理、网络认证页还是安全软件的 HTTPS 检查引起。

1. 下载 1.0.2 或更新版本，完整解压后重新运行。新版会自动尝试备用下载器。
2. 检查电脑日期、时间和时区是否准确，并完成 Windows 更新。如果配置了代理或网络认证，先确认浏览器能正常访问官方下载页面；组织网络的证书问题请交由管理员核对。
3. 若浏览器能下载而脚本仍失败，打开错误窗口显示的**官方文件地址**。Windhawk 1.7.3 安装包地址为 [官方下载](https://github.com/ramensoftware/windhawk/releases/download/v1.7.3/windhawk_setup_offline.exe)。
4. 双击 **导入下载文件.cmd**，把下载完成的单个文件拖入窗口，按 Enter。无需改名；工具按固定版本 SHA256 识别，并为安装包验证 Authenticode 签名。
5. 看到导入成功后重新运行 **应用民办mac.cmd**。若后续模组文件也下载失败，可以按提示的官方地址逐个下载并导入。

如果浏览器也提示证书异常，先处理系统或网络的证书问题。不要选择忽略证书错误；导入不会接受错误页、其他版本或签名不受信任的安装包。导入仅准备缓存，不启动安装包，也不修改任务栏。

## 搜索仍是输入条，或输入框出现在任务栏里

打开“任务栏设置.cmd” → 搜索 → 仅搜索图标。也可右键任务栏进入设置。本项目只约束原生搜索图标宽度，不用裁切输入条或替换 XAML 内容来伪造图标。

Windows 不允许脚本修改搜索设置时会显示提示。你的手动修改不会被记为脚本改动，恢复时可能仍需自己切回原搜索模式。

## 显示“已有标准版 Windhawk 服务”

这表示已有另一套安装，脚本尚未切换。到原 Windhawk 设置中处理服务和启动方式，或继续在原软件里手动导入 presets 中的设置。不要让两套 Windhawk 同时运行。本包不会擅自停用系统服务。

便携版的当前用户登录任务和启动快捷方式可自动备份，但复杂脚本、Run 注册表、其他用户启动项不自动处理。

## 圆角没出现，或 90 秒内未确认加载

确认没有 ExplorerPatcher 等替换任务栏的软件，并保持默认 Windows 11 任务栏。首次下载符号需要网络；资源管理器或系统更新后，上游模组也可能不兼容。

脚本检查的是启用的 DLL 是否加载进当前会话的 Explorer，不能保证每项视觉行为均正确；新系统版本应试用验证。超时或应用异常会尝试撤回，保留数据记录。恢复后可稍后重试；本包不自动重启 Explorer。

## 登录时先出现原任务栏

登录任务已配置无额外延迟，但依赖 Windows 登录、Explorer 初始化及模组加载，无法保证开机第一帧就是新样式。Windows 符号下载、安全软件及磁盘速度都可能影响时间。

## 动画仍然卡、耗电或时钟不完整

目标帧率 90 并非实际保证帧率。高刷、多屏、缩放比例和 GPU 负载可能影响效果。时钟已使用 0 上下内边距与最小高度 48，但尚未覆盖所有缩放组合。

整条任务栏的目标90帧不等于实际帧率；Beta独立提醒固定16毫秒计时，没有90帧选项。普通用户不必直接改脚本。若无法接受，使用恢复入口。

## 无法创建登录任务

组织策略或权限限制可能禁止注册任务。脚本会尝试恢复原方案，不自动提升后台权限或安装服务。请保留错误文字和本地 state.json，检查任务计划程序中是否有同名任务被占用。

## 恢复提示“被其他操作改变”

工具发现某项设置、启动任务或快捷方式和它应用时记录的内容不同，会保留你后来的修改。此类项目需要你检查；它不会强行覆盖。可在本机 state.json 查看原值和原路径，这份文件可能包含个人信息，不要上传。

## 运行目录缺少标记或安装中断

工具不会覆盖无法确认归属的 Runtime。如果尚未应用成功且没有正在运行的本包 Windhawk，先保留该目录以便排查，再手动将 Runtime 改名，重新应用。不要删除 state.json 或 Backups 来“解决”恢复问题。

## 要完全移除

先双击“恢复原任务栏.cmd”，确认原方案恢复，处理所有警告。退出本包窗口后再自行删除解压的项目文件夹和 %LOCALAPPDATA%\MinbanMac。该目录包含安装文件、缓存和恢复记录，删除后无法再使用这些备份。没有自动清空此目录的脚本。

## Beta独立提醒异常

先确认应用仍有任务栏按钮，并发出了原生闪烁提醒；只有右下角系统通知时可能不会抬升。QQ曾需重启后恢复。可双击“关闭独立提醒.cmd”，保留任务栏美化。重新启用请用同包的“开启独立提醒.cmd”。开关提示尚未启用时，先运行完整应用入口；不要用别人的运行配置或恢复记录替换自己的文件。

附带组件或源码校验失败时重新完整解压Beta ZIP，不跳过哈希检查。从GitHub“Source code”下载的源码不含DLL，普通用户请选择发布页的完整切换包。

任务栏迟收回时，记录是否还有菜单、搜索或托盘面板、是否有应用闪烁、点击回最大化窗口能否解除。当前按同屏幕任意可见最大化窗口判断隐藏，窗口切换延迟仍在Beta验证范围。

TranslucentTB相关功能在本包启用时可能被阻止，这是优先保留Windhawk样式的冲突策略。完整恢复按本机原记录恢复其启动状态；独立提醒开关不改变此策略。

## 下载并启用

### [前往下载页](https://github.com/Holmes-zhang/minban-mac/releases)

选择 **minban-mac-1.1.0-beta.1.zip**。从别人手里收到这个完整测试包，也可直接按下面的步骤启用。

1. **完整解压**到普通文件夹。
2. 双击 **应用民办mac.cmd**。
3. 等待“应用完成”；下次登录会自动加载。

**只运行这一个启用入口即可，不需要另外安装提醒组件。** 不要在压缩包内直接运行，也不要只下载单个cmd文件。GitHub的“Source code”是源码包，未包含编译后的提醒DLL，普通用户请下载完整切换包。

**保留你自己的壁纸、桌面文件和应用排列。** 首次需要联网下载约142 MiB的官方Windhawk安装包及四个上游模组；独立图标提醒已随包附带。首次加载Windows内部符号也可能需要联网。

| 想做什么 | 双击哪个文件 |
| --- | --- |
| 启用整套方案 | 应用民办mac.cmd |
| 只关闭独立图标提醒 | 关闭独立提醒.cmd |
| 重新开启独立图标提醒 | 开启独立提醒.cmd |
| 回到启用前的任务栏方案 | 恢复原任务栏.cmd |

**这是Beta，适合愿意反馈问题的用户。** QQ提醒偶尔需重启应用，窗口关闭后任务栏迟收回的问题仍待验证；不同Windows补丁、多屏及全新电脑首次安装尚未完整实机回归。详见[Beta测试说明](docs/BETA.md)。

## 这版有什么

- **圆润悬浮**：居中的应用组与独立时间组，空白区域穿透。
- **需要时出现**：同屏幕还有可见的最大化窗口时允许自动隐藏；鼠标移到应用组或时间组对应的底边唤起。普通小窗口覆盖背景最大化窗口时也会自动隐藏。
- **独立图标提醒**：隐藏时，有任务栏按钮的应用请求闪烁，自己的真实图标从当前按钮位置单独升起，约1.2秒后收回。连续闪烁不延长显示，后台仅托盘应用忽略。
- **快速唤起**：缩短等待并加快原生动画。实际流畅度取决于系统负载，不保证固定帧率。
- **保留搜索**：放大镜打开Windows原生搜索。
- **减少冲突**：启用时记录并暂停原有TranslucentTB；自动阻止其他工具争用任务栏样式接口。恢复时按本地记录撤回。
- **随时撤回**：独立提醒可以单独关闭，重新应用会记住选择；完整恢复会退出本包并恢复记录中的原启动项和显示设置。

| 项目 | 支持情况 |
| --- | --- |
| 系统 | Windows 11 x64 |
| Windows 10 / ARM64 | 暂不支持 |
| 首次使用 | 需要联网 |
| 多屏、不同缩放与Windows补丁 | 尚未完整实机验证 |
| 所有应用提醒 | 不保证；仅系统弹窗而无任务栏闪烁时可能不触发 |

本机基线是Windows 11 build 26200 / Explorer 10.0.26100.9444。QQ、微信真实提醒已在本机出现，不能据此保证所有电脑都兼容。隔离检查覆盖安装恢复逻辑、哈希校验和组件开关，范围见[验证记录](docs/VALIDATION.md)。

若已有其他任务栏美化，请先退出。检测到标准安装版Windhawk服务时，本包停止并提示处理原安装。定位依赖Windows内部符号，组件无法加载时会提示并尝试撤回。

## 常见问题

**搜索还是长条？**

双击“任务栏设置.cmd” → 搜索 → 仅搜索图标。部分Windows版本需要手动设置一次。

**只有右下角系统消息，没有独立图标？**

先确认应用最小化后仍有任务栏按钮。只有系统通知、不发任务栏闪烁信号时可能不触发；QQ曾在本机重启后恢复。提醒异常可先双击“关闭独立提醒.cmd”，其余任务栏样式继续保留。

**任务栏迟迟不收回？**

开始菜单、搜索、预览或托盘面板还在使用时，原生任务栏可能保持显示。所有面板关闭、鼠标离开且仍有最大化窗口时若长期不收回，请记录前几步操作并反馈。此次隐藏判断调整仍需实机验证。

**下载失败或证书报错？**

确认能访问GitHub；需要代理时双击“网络设置.cmd”，填写自己的代理。两条下载路径均保留HTTPS证书校验，下载内容校验失败不会执行。浏览器下载官方文件后，可双击“导入下载文件.cmd”校验并复用。详见[故障处理](docs/TROUBLESHOOTING.md)。

**想换回去，或应用失败？**

双击“恢复原任务栏.cmd”。恢复会保留你后来改过的设置，并提示无法自动恢复的事项。请保留本机恢复记录。

**开机先出现原任务栏？**

需等待Explorer初始化与模组加载，无法保证第一帧就是新样式；登录启动没有额外延迟。
